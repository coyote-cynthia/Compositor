# Compositor 1.5.4 — Intel / macOS 14 兼容预发布

这是 coyote-cynthia 维护的兼容发行版，基于 robbietilton/Compositor；不是上游官方发行。

## 下载

推荐 `Compositor-Intel-macOS14.dmg`。打开 DMG，将应用拖入 Applications。
也提供应用 ZIP 和 SHA256SUMS.txt；在下载目录执行 `shasum -a 256 -c SHA256SUMS.txt` 校验。

## 构建来源

- 应用内版本：1.5.4（50）。
- 二进制构建提交：`af58986`，分支 `codex/intel-macos14`。
- 成功的构建：https://github.com/coyote-cynthia/Compositor/actions/runs/39711588199
- Xcode 26.1.1，Intel x86_64，最低 macOS 14.0。
- 本次发行标签指向文档更新提交，应用代码与上述构建提交相同。

## 兼容改动

保留 Swift / AppKit / Metal 架构，修复旧系统 UI API、RAW 高光恢复可用性、Metal 缓冲区同步锁及 PDF/Camera Raw 类型检查问题。测试配置统一为 Intel。

## 已知限制

- 编译、打包、下载文件 SHA-256 和 DMG 完整性验证通过。
- Verify 尚未通过：DeepLayerTests.swift 类型检查超时；截图测试未加载 accessibility。
- 尚未完成 macOS 14.1 实机启动、编辑、保存重开及导出验收。
- macOS 26 以下不提供 RAW Highlight Recovery；部分工具栏和光标外观与上游不同。
- 安装包为 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证，系统可能拦截首次打开。
- 已关闭上游自动更新，以免安装不适用的上游版本；后续请从本仓库手动下载。

请作为实验性预发布试用，不视为已通过完整测试的稳定版。
